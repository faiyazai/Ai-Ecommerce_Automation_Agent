Welcome to the repository for my **AI-powered E-Commerce Automation System**. This project demonstrates a fully functional, end-to-end automation workflow designed to run an e-commerce business completely on autopilot.

## ✨ Key Features

* **Automated Product Creation:** Simply enter a product name and price into a Google Sheet. The AI automatically generates an SEO-friendly description, creates high-quality AI images, and instantly publishes the product directly to the e-commerce store.
* **Instant Inventory Management:** Update pricing, edit descriptions, or delete products in seconds, directly from the Google Sheet without touching the website backend.
* **Automated Daily Analytics & Invoices:** At the end of every 24 hours, the system generates a comprehensive daily sales report and emails it to the admin. It tracks total revenue, best-selling items, new customers, and provides links to auto-generated invoices.
* **Chatbot Integration:** The entire workflow can be triggered and managed via simple text commands on WhatsApp or Telegram.
